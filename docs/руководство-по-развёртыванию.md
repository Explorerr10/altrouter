# AltRouter — руководство по развёртыванию

## Требования

Debian с systemd-networkd (сеть роутера генерируется в `.network`-файлы). Пакеты: `python3-venv`, `dnsmasq`, `wireguard-tools`, `openssl`, `curl` (ставит `prepare-server.sh`); `ppp`, `traceroute`, `tcpdump` доустанавливает `install.sh`. Файрвол — nftables, DHCP — dnsmasq (их конфиги пишет хелпер панели, автозапуск юнитов включается при установке).

## Первичная установка

1. Подготовить сервер (выполняется от root):
   ```
   bash deploy/prepare-server.sh
   ```
   Ставит пакеты и отключает автозапуск dnsmasq (панель им управляет сама).

2. Передать tarball с `backend/app`, `backend/requirements.txt`, `backend/pyproject.toml`, `frontend/dist`, `deploy` на сервер и выполнить:
   ```
   sudo bash deploy/install.sh /tmp/altrouter-deploy
   ```
   `install.sh` делает:
   - системного пользователя `altrouter` (home `/opt/altrouter`, группа `systemd-journal` для чтения journalctl);
   - каталоги `/opt/altrouter/{backend,frontend,certs,backups}` и `/etc/altrouter`;
   - venv + pip-зависимости;
   - самоподписанный TLS-сертификат на 10 лет (`/opt/altrouter/certs/altrouter.crt|.key`, SAN — IP сервера), ключ `chmod 600`;
   - sudoers (`deploy/sudoers.altrouter`, `visudo -cf` перед установкой) и хелперы `/usr/local/sbin/altrouter-netapply`, `/usr/local/sbin/altrouter-ssh`;
   - IP-форвардинг через `/etc/sysctl.d/90-altrouter.conf`;
   - systemd-юнит `/etc/systemd/system/altrouter.service`, `enable altrouter nftables dnsmasq`, рестарт и статус.

После установки панель: `https://<ip>:9000`, первый вход `admin`/`admin` — смените пароль.

## Юнит altrouter.service

```
User=altrouter
Environment=ALTROUTER_STATIC_DIR=/opt/altrouter/frontend
ExecStart=/opt/altrouter/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 9000 \
  --ssl-certfile /opt/altrouter/certs/altrouter.crt --ssl-keyfile /opt/altrouter/certs/altrouter.key
Restart=on-failure, RestartSec=3
```

Nginx и другие reverse-proxy не нужны — TLS терминирует сам uvicorn; порт только 9000/TCP.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ALTROUTER_CONFIG_DIR` | `/etc/altrouter` | Каталог состояния (учётные записи, сеть) |
| `ALTROUTER_MGMT_IFACE` | `enp9s0f0` | Management-интерфейс, исключается из настройки |
| `ALTROUTER_STATIC_DIR` | — (задаётся в юните) | Каталог собранного фронтенда |
| `ALTROUTER_CONFIRM_TIMEOUT` | `180` | Секунды до автоотката неподтверждённой транзакции |

## Обновление (с машины разработчика, Windows)

```
$env:ALTROUTER_SUDO_PW='<sudo-пароль linadmin>'
powershell -NoProfile -ExecutionPolicy Bypass -File deploy/deploy.ps1 -Server <ip> -SkipBuild
```

`deploy.ps1`: собирает фронтенд (`npm run build`, пропускается с `-SkipBuild`), пакует tar, льёт по scp, выполняет `install.sh` через sudo, в конце проверяет `/api/health`. Рестартуется только юнит `altrouter` — сетевые сессии не рвутся, но активные сессии панели (cookie) сбрасываются, нужен повторный вход.

## Состояние на сервере

| Путь | Содержимое |
|---|---|
| `/etc/altrouter/config.json` | Учетные записи панели |
| `/etc/altrouter/access.json` | Настройки доступа (Управление → Доступ) |
| `/etc/altrouter/network/network.json` | Желаемое состояние сети (см. «Формат конфигурации») |
| `/etc/altrouter/network/staging/` | Сгенерированные конфиги (networkd, dnsmasq, nftables) |
| `/etc/altrouter/network/backups/<ts>-<tx>/` | Снимок staging перед каждой транзакцией |
| `/etc/altrouter/network/pending.json` | Незавершённая транзакция |
| `/etc/altrouter/network/journal.jsonl` | Журнал транзакций |

## Восстановление

- Активная транзакция: `POST /api/network/interfaces/rollback` или баннер в UI; автооткат по таймауту.
- Ручной откат: скопировать файлы из последнего `backups/<ts>-<tx>/` в `staging/` и перезапустить `altrouter-netapply` (или службу `altrouter`).
- Полный бэкап/рестор — через UI (Управление → Резервная копия; архив включает `config.json`, `network/network.json`, `network/journal.jsonl`).

## Известные ограничения

- Раздел VPN (WireGuard) — экспериментальный, не поддерживается.
- IPv6 не настраивается (только IPv4).
- Сертификат самоподписанный: для браузера нужно одноразовое подтверждение исключения.
